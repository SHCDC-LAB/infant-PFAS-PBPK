- [ ] Confirm exact PBPK source version used to generate manuscript results (see VERSION_AUDIT.md).
- [ ] Run the primary pipeline from a clean R session with the authorized local input workbook.
- [ ] Confirm all 175 infants and all six PFAS are retained.
- [ ] Compare EDI summaries against main Table 1 and Supplementary Tables S12–S13.
- [ ] Compare day-365 plasma and organ CTWA against main Table 2 and Supplementary Table S14.
- [ ] Compare organ contribution summaries against main Table 3 and Supplementary Table S16.
- [ ] Compare all three compound-specific RSP scenarios and RBMDL10 summaries against main Table 4 and Supplementary Table S15.
- [ ] Confirm Figure 1–4 and Supplementary Figure S1 visually and numerically match the submitted manuscript.
- [ ] Confirm model qualification and sensitivity outputs match Supplementary Tables S5–S11.
- [ ] Confirm no participant-level data, raw data, generated workbooks, caches, or logs are staged for commit.
- [ ] Add the authors' approved license and repository citation metadata.
- [ ] Tag the exact public release commit used for submission.
